# Azure Terraform GitHub Actions

## Overview

This project demonstrates Azure infrastructure automation using Terraform and GitHub Actions.

The goal is to implement a professional Infrastructure as Code and CI/CD workflow following modern DevOps practices.

## Technologies

* Microsoft Azure
* Terraform
* Git
* GitHub
* GitHub Actions
* Microsoft Entra ID
* OIDC / Workload Identity Federation

## Planned Workflow

Feature Branch → Pull Request → CI Validation → Terraform Plan → Code Review → Main → Terraform Apply
